# Лабораторная работа 5

Приложение для заметок с тегами, поиском и фильтрацией.

## Задание

Вариант 33.

Реализовать React-приложение для управления заметками:

- создание, редактирование и удаление заметок;
- организация заметок в группы по тегам;
- поиск по содержимому заметок;
- фильтрация по группам, тегам и дате;
- сохранение состояния в `localStorage`.

## Реализация

Приложение построено на React 18 с использованием Vite и функциональных
компонентов. Состояние хранится в `useState`, синхронизация с `localStorage` —
через `useEffect`.

Интерфейс разделён на две области: слева — список заметок с поиском и фильтрами,
справа — форма создания и редактирования. Выбор заметки в списке переключает
форму в режим редактирования.

Заметка содержит поля `id`, `title`, `content`, `tags`, `createdAt`,
`updatedAt`. Идентификатор генерируется через `crypto.randomUUID()`.

Поиск фильтрует заметки по совпадению с заголовком или содержимым без учёта
регистра. Фильтр по тегам строится из уникальных тегов всех заметок. Фильтр по
дате поддерживает диапазоны «Сегодня», «Неделя», «Месяц». Все три фильтра
применяются последовательно.

## Структура

- `src/main.jsx` — точка входа, монтирует `<App />` в `#root`;
- `src/App.jsx` — состояние приложения, логика фильтрации, обработчики;
- `src/components/SearchBar.jsx` — поле поиска;
- `src/components/FilterBar.jsx` — панель фильтров по тегам и дате;
- `src/components/NoteForm.jsx` — форма создания и редактирования;
- `src/components/NoteList.jsx` — список заметок;
- `src/components/NoteItem.jsx` — карточка заметки.
