# Лабораторная работа 4

## Задание

Задача 4. Класс Movie с полями title, director, actors и методами addActor,
removeActor, геттером castSize. Функции группировки фильмов по режиссёру, по
количеству актёров, получения уникальных актёров, фильмов конкретного актёра и
списка всех названий. UI со списком фильмов, добавлением/удалением фильмов и
актёров, асинхронными операциями через Promise + setTimeout и сохранением в
localStorage.

## Реализация

Класс Movie и функции группировки вынесены в model.js. main.js хранит массив
фильмов, все операции (добавление/удаление фильма и актёра) обёрнуты в Promise с
setTimeout для имитации асинхронности, после каждой операции состояние
сохраняется в localStorage и вызывается render() для обновления интерфейса.

## Запуск

Откройте index.html в браузере.
