# Лабораторная работа 2

## Задание

Задача 2. Написать функцию calculateExpression(expr), вычисляющую значение
математического выражения в строке (например, "2 + 3 * 4" → 14).

## Реализация

Функция calculateExpression реализована через рекурсивный спуск (recursive
descent parser) без использования eval(). Строка разбивается на токены, после
чего parseExpr обрабатывает сложение и вычитание, parseTerm — умножение и
деление, parseFactor — числа, скобки и унарный минус. Порядок вызовов функций
задаёт приоритет операций.

## Запуск

Вызовите calculateExpression("2 + 3 * 4") в Node.js или подключите скрипт в
HTML-страницу.
