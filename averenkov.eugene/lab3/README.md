# Лабораторная работа 3

## Задание

Задача 3. Реализуйте функцию findMostFrequent(arr), которая возвращает самый
часто встречающийся элемент в массиве.

## Реализация

Функция findMostFrequent проходит массив один раз, подсчитывая количество
вхождений каждого элемента через Map. При обновлении счётчика элемент
сравнивается с текущим максимумом, и при превышении становится новым кандидатом
на самый частый. При равенстве частот сохраняется элемент, встретившийся раньше.
Сложность O(n) по времени и O(n) по памяти.

## Запуск

Вызовите findMostFrequent([1, 2, 2, 3, 2, 1]) в Node.js или подключите скрипт в
HTML-страницу.
