# Лабораторная работа 5

## Задание

Задача 5. Реализовать слайдер книг в книжном интернет-магазине. Создать слайдер
на главной странице магазина, состоящий из карточки книги. Карточка должна
содержать обложку книги, название, рейтинг, описание и цену. Функционал
слайдера:

- кнопки «Далее» и «Назад»;
- подпись текста к каждому слайду;
- вывод номера и максимального количества слайдов (1/3, 2/3, 3/3);
- пагинация (при клике переключается на нужный слайд).

## Реализация

Приложение построено на React 18 с использованием функционального компонента и
хука useState. Проект собирается через Vite. Точкой входа служит файл
src/main.jsx, который монтирует корневой компонент App в элемент с id root,
описанный в index.html. Стили подключаются из src/styles.css, обложки книг лежат
в каталоге assets и импортируются в main.jsx как обычные модули.

Данные о книгах хранятся в массиве books в начале файла src/main.jsx. Каждая
книга описывается объектом с полями title, image, rating, description, price и
caption. Поле caption содержит подпись, которая выводится под карточкой. Один
элемент массива соответствует одному слайду, поэтому количество слайдов
определяется длиной массива.

Состояние слайдера хранится в одной переменной current, которая содержит номер
текущего слайда, начиная с нуля. На экране отрисовывается только карточка
books[current]: обложка, название, рейтинг, описание и цена. Остальные слайды в
разметке не создаются и не скрываются через CSS. При изменении current React сам
перерисовывает карточку, подпись, счётчик и пагинацию.

Кнопки «Назад» и «Далее» вызывают функции prev и next. Они уменьшают или
увеличивают current на единицу. Слайдер работает по кругу: с первого слайда
кнопка «Назад» ведёт на последний, а с последнего кнопка «Далее» ведёт на
первый. Номер слайда выводится в формате «текущий / всего», где текущий номер
равен current + 1, а общее количество равно books.length.

Пагинация создаётся методом map по массиву books: для каждой книги выводится
точка. Точка текущего слайда получает дополнительный класс active и выделяется
цветом. При клике на точку вызывается setCurrent с номером этой точки, и слайдер
сразу переключается на нужный слайд. Для каждой точки задан атрибут key на
основе названия книги, чтобы React корректно отслеживал элементы списка.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
