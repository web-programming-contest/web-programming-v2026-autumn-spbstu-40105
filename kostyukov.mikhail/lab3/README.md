# Лабораторная работа 3

## Задание

Вариант 5. Реализуйте функцию chunkArray(arr, size), которая разбивает массив на
подмассивы указанного размера.

## Реализация

1. Есть проверки, что `arr` является массивом, а `size` — положительным целым
   числом. При невалидных параметрах возвращается пустой массив.
2. В цикле с шагом `size` извлекаются подмассивы элементов и добавляются в
   `result`.
3. Возвращается массив полученных подмассивов.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
