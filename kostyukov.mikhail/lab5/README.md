# Лабораторная работа 5

## Задание

Вариант 5. Реализовать механику списка в книжном интернет-магазине. Создать
компонент списка в виде дерева (tree). Добавить возможность скрывать/раскрывать
ветки. Структура дерева (по уровням):

- Автор;
- Издательство;
- Жанр;
- Название книги.

## Реализация

Интерфейс построен на React. Данные организованы в иерархическую структуру из
четырёх уровней: автор, издательство, жанр и название книги. Компонент
`TreeNode` рекурсивно рендерит дочерние элементы дерева. Состояние видимости
каждой ветки контролируется с помощью `useState`. Ветки скрываются и
раскрываются по клику на узел.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
