# Лабораторная работа 1

## Задание

Вариант 34. Задача 1. Создать меню блюд, используя неупорядоченный список. Меню
должно удовлетворять следующим требованиям:

- Каждый пункт меню (`<li>`) состоит из названия блюда и цены;
- Название блюда располагается в левом краю контейнера, а цена прижимается к
  правому краю, независимо от длины названия блюда;
- Каждый пункт меню занимает всю ширину контейнера `<ul>`;
- Ширина контейнера `<ul>` — 400px;
- Между элементами списка должен быть вертикальный отступ 16px;
- Элементы списка разделены сплошной черной линией, толщина которой составляет
  1px.

## Реализация

- Разметка страницы выполнена на основе семантического неупорядоченного списка
  `<ul>` и элементов `<li>`.
- Сохранена базовая структура шаблона с заголовком первого уровня `<h1>` и
  центрированием основного блока.
- Фиксированная ширина контейнера меню `400px` задана классу `.menu-list`.
  Список отцентрирован по горизонтали с помощью `margin: 0 auto`.
- Для пунктов меню (`.menu-item`) применён Flexbox
  (`display: flex; justify-content: space-between`), гарантирующий прижатие
  названия блюда к левому краю и цены к правому.
- Пункты меню занимают 100% ширины родительского контейнера.
- Требуемый вертикальный отступ в 16px реализован симметрично: по `8px` сверху и
  снизу каждого пункта меню (`padding: 8px 0`). Суммарно между строками смежных
  блюд получается ровно 16px, а разделитель находится строго по центру.
- Сплошная черная линия толщиной 1px реализована через
  `border-bottom: 1px solid #000`.
- У первого элемента списка через `:first-child` убран верхний отступ, а у
  последнего через `:last-child` отключены нижний отступ и разделительная черта,
  так как линия должна быть только между элементами.

## Запуск

Откройте `index.html` в браузере.
