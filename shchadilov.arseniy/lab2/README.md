# Лабораторная работа 2

## Задание

Вариант 34. Задача 2. Создать функцию `isBalanced(str)`, проверяющую
сбалансированность скобок `()[]{}` в строке (например: `"{[()]}"` → `true`,
`"[(])"` → `false`).

## Реализация

- Экспортируется именованная функция `isBalanced(str)` из `solution.js`.
- Алгоритм: стек на базе массива, `Set` для открывающих скобок и `Map` для
  сопоставления закрывающих скобок с открывающими. Открывающие скобки
  добавляются в стек, при встрече закрывающей проверяется соответствие верхнего
  элемента стека. Строка сбалансирована, если после обхода стек пуст.
- Граничные случаи:
  - `""` (пустая строка) → `true`;
  - непарные скобки (`"("`, `")"`) или нарушение порядка (`"[(])"`) → `false`;
  - символы, не являющиеся скобками, игнорируются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {isBalanced} from './solution.js';

console.log(isBalanced('{[()]}')); // true
```
