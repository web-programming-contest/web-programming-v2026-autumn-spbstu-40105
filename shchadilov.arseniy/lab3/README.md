# Лабораторная работа 3

## Задание

Вариант 34. Задача 3. Реализовать функцию `findPairsWithSum(arr, sum)`, которая
возвращает все пары чисел из массива `arr`, дающие в сумме `sum`.

## Реализация

- Экспортируется именованная функция `findPairsWithSum(arr, sum)` из
  `solution.js`.
- Алгоритм: перебор всех пар элементов с индексами `i < j`. Если
  `arr[i] + arr[j] === sum`, пара `[arr[i], arr[j]]` добавляется в
  результирующий массив.
- Граничные случаи:
  - пустой массив или массив короче 2 элементов → `[]`;
  - отсутствие подходящих пар → `[]`;
  - один и тот же элемент (одинаковый индекс) не используется в паре дважды, но
    одинаковые числа на разных индексах корректно образуют пару;
  - некорректные входные данные безопасно пропускаются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {findPairsWithSum} from './solution.js';

console.log(findPairsWithSum([1, 2, 3, 4, 5], 6)); // [[1, 5], [2, 4]]
```
