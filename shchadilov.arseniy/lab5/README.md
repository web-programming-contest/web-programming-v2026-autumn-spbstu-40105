# Лабораторная работа 5

## Задание

Вариант 34. Задача 5. Создать React-приложение прогноза погоды с использованием
открытого API:

- отображение текущей погоды с основными показателями (температура, ощущаемая
  температура, влажность, скорость ветра, описание);
- смена города через форму поиска;
- переключение интервала прогноза (1 день, 3 дня, 7 дней).

## Реализация

- **`src/App.jsx`**: состояние города (`cityInput`), интервала (`daysCount`),
  текущей погоды и прогноза (`weather`), загрузка и обработка ошибок; элементы
  контракта `weather-city`, `weather-submit`, `weather-current` и
  `weather-forecast`.
- **`src/weatherService.js`**: интеграция с открытым Open-Meteo API (геокодинг +
  прогноз на 7 дней без API-ключа) и безопасный локальный fallback для работы в
  изолированном/офлайн-окружении без сетевых ошибок.
- **`src/main.jsx` и `src/styles.css`**: точка входа React 18 с привязкой к
  `[data-testid="app"]` и адаптивная сетка без горизонтальной прокрутки.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
