# Лабораторная работа 1

## Задание

Вариант 22, задача 1. Создать страницу с текстом, где подчёркивание слов
реализовано не стандартным способом (не через `text-decoration: underline`), а с
помощью кастомных CSS-свойств. Подчёркивание должно имитировать стандартное, но
создаваться иначе.

## Реализация

Подчёркивание реализовано через
`background-image: linear-gradient(currentColor, currentColor)` в паре с
`background-size` и `background-position`. Такой градиент даёт сплошную полосу
цвета текста (`currentColor`), которая растягивается на всю ширину слова
(`background-size: 100% var(--underline-thickness)`) и прижимается к нижнему
краю элемента с небольшим отступом
(`background-position: 0 calc(100% - var(--underline-offset))`), чтобы не
сливаться с буквами, у которых есть нижние выносные элементы («р», «у», «д»).

Толщина и отступ линии вынесены в CSS-переменные `--underline-thickness` и
`--underline-offset`, что позволяет классу-модификатору `.underline-thick`
переопределить их без дублирования остальных стилей.

## Запуск

Открыть файл `index.html` в браузере — сборка и зависимости не требуются.
