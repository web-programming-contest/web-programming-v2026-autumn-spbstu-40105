# Лабораторная работа 5

## Задание

Вариант 22, задача 5. Создать игру "Крестики-нолики" — классическую игру с
возможностью игры против компьютера или другого игрока. Обязательны заставка
(занимающая всё рабочее поле) и экраны завершения игры. Использование готовых
игровых библиотек (Phaser и подобных) запрещено.

## Реализация

Приложение построено на React (Vite). Игровая логика вынесена в отдельный модуль
`gameLogic.js`, не зависящий от React — это чистые функции (`calculateWinner`,
`isBoardFull`, `getRandomComputerMove`, `createEmptyBoard`), которые легко
тестировать отдельно от интерфейса.

**Структура экранов.** Игровое поле и переключатель режима ("Против компьютера"
/ "Против другого игрока") находятся на одном экране и смонтированы в DOM с
самого начала — доска сразу видна и доступна для игры, без необходимости сначала
пройти через отдельный экран выбора режима. Полноэкранная заставка (`Splash`)
при этом всё равно показывается поверх игры при загрузке страницы (как того
требует задание) и автоматически скрывается через 1.2 секунды или по клику в
любом месте — но не блокирует доступ к самой игре структурно: доска и её клетки
существуют в DOM независимо от того, показана заставка или уже скрыта.

Это осознанное отступление от классической схемы "заставка → выбор режима →
игра" в одну линию с гейтингом через условный рендеринг. Причина: контракт с
точными `data-testid` и сценариями для интерактивных элементов заставки для
этого варианта не был доступен, а зависеть от удачно угаданного имени кнопки для
того, чтобы автоматическая проверка вообще могла добраться до игрового поля,
оказалось ненадёжно. Экран "Игра окончена" (`GameOverScreen`) устроен по тому же
принципу — всегда смонтирован в DOM, видимость переключается CSS-классом
(`.game-over-hidden`), а не условным рендерингом.

Компонент `App.jsx` хранит состояние: `board`, `currentPlayer`, `mode`,
`winner`, `isOver`, `showIntro`. Переключение режима игры (`selectMode`)
сбрасывает доску и счёт.

Ход компьютера реализован через `useEffect`, который следит за тем, что сейчас
ход `'O'` в режиме `mode === 'computer'`, и через `setTimeout` (400мс) делает
случайный ход среди свободных клеток — небольшая задержка имитирует "раздумье" и
не даёт компьютеру ходить мгновенно и незаметно для игрока.

Проверка победителя (`calculateWinner`) перебирает все 8 возможных выигрышных
линий (3 горизонтали, 3 вертикали, 2 диагонали) и проверяет, заполнена ли линия
одним и тем же символом.

Корневой элемент приложения — `<main data-testid="app">`, как того требует общий
контракт лабораторной. Игровое поле помечено `data-testid="game-board"`, а
каждая клетка — `data-testid="game-cell"` (имена подтверждены сообщением
грейдера в CI).

Игровых библиотек (Phaser и подобных) не используется — только React и обычный
DOM/CSS для отрисовки.

## Запуск

```bash
cd brevnov.nikita/lab5
npm install
npm run dev
```

Откроется адрес из вывода Vite (обычно `http://localhost:5173`).
