# Лабораторная работа 3

## Задание

Вариант 22, задача 3. Реализовать функцию `findPairsWithSum(arr, sum)`, которая
возвращает все пары чисел массива, дающие в сумме `sum`.

## Реализация

Функция перебирает все возможные пары индексов `i < j` в массиве (два вложенных
цикла) и проверяет, равна ли сумма элементов на этих позициях заданному числу
`sum`. Если равна — пара значений `[arr[i], arr[j]]` добавляется в результат.

Перебор по индексам, а не по уникальным значениям, выбран намеренно: так
повторяющиеся числа в массиве корректно порождают несколько пар, если у них есть
на что "опереться" на других позициях (например,
`findPairsWithSum([2, 2, 3], 5)` вернёт две пары `[2, 3]` — по одной на каждую
двойку).

Сложность решения — O(n²), что приемлемо для лабораторной работы; более быстрый
вариант (O(n) с хэш-таблицей остатков) возможен, но усложняет обработку
дубликатов и здесь не потребовался.

Граничные случаи:

- пустой массив и массив из одного элемента возвращают `[]` (пары физически
  невозможны);
- если ни одна пара не подходит — возвращается `[]`;
- отрицательные числа и повторяющиеся значения обрабатываются корректно;
- входной массив `arr` не изменяется — функция только читает его.

## Запуск

```js
import {findPairsWithSum} from './solution.js';

console.log(findPairsWithSum([1, 2, 3, 4], 5)); // [[1, 4], [2, 3]]
```

Файл — ES-модуль, сборка не требуется.
