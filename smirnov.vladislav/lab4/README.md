# Лабораторная работа 4

## Задание

Вариант 31. Разработать приложение для управления рецептами.

Реализовать класс Recipe с названием рецепта, списком ингредиентов и шагами
приготовления. Добавить методы для работы с ингредиентами и функции обработки
коллекции рецептов.

Создать веб-интерфейс для добавления, просмотра, изменения и удаления рецептов.
Реализовать асинхронные операции и сохранение данных в localStorage.

## Реализация

В файле model.js находится класс Recipe и функции для работы с коллекцией
рецептов: группировка по количеству ингредиентов, получение уникальных
ингредиентов, поиск рецептов по ингредиенту, группировка по количеству шагов,
получение названий рецептов.

В файле main.js реализована работа с DOM: создание карточек рецептов, обработка
формы и кнопок управления.

Добавление и удаление выполняются асинхронно с использованием Promise и
setTimeout. Данные сохраняются в localStorage и восстанавливаются после
перезагрузки страницы.

В файлах index.html и styles.css реализованы структура и оформление интерфейса.

## Запуск

Откройте `index.html` в браузере.
