# Лабораторная работа 2

## Задание

Вариант 31. Написать функцию isPerfectNumber, проверяющую, является ли число
"совершенным" (сумма делителей равна числу, исключая само число).

## Реализация

Функция isPerfectNumber перебирает все числа от 1 до числа, не включая его само.
Если число является делителем исходного числа, оно добавляется к общей сумме.
После завершения цикла функция сравнивает сумму делителей с исходным числом и
возвращает true или false.

## Запуск

импортировать isPerfectNumber из файла `solution.js` в другом JavaScript ES
module и вызвать её с нужным числом.
