# Лабораторная работа 3

## Задание

Вариант 31. Реализуйте функцию intersection(arr1, arr2), которая возвращает
массив общих элементов.

## Реализация

Функция перебирает элементы первого массива с помощью цикла for. Для каждого
элемента она проверяет все элементы второго массива. Если элементы совпадают,
найденный элемент добавляется в результирующий массив с помощью push. После
этого внутренний цикл прекращает работу с помощью break. В конце функция
возвращает результирующий массив. Исходные массивы не изменяются.

## Запуск

Для проверки функции необходимо импортировать intersection из файла
`solution.js` в другом JavaScript ES module и вызвать её с двумя массивами.
