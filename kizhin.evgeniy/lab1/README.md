# Лабораторная работа 1

## Задание

Вариант 34. Создать меню блюд, используя неупорядоченный список. Меню должно
удовлетворять следующим требованиям:

- Каждый пункт меню (`<li>`) состоит из названия блюда и цены;
- Название блюда должно располагаться в левом краю контейнера, а цена должна
  прижиматься к правому краю, независимо от длины названия блюда (необходимо
  использовать Flexbox или Grid);
- Каждый пункт меню должен занимать всю ширину контейнера `<ul>`;
- Ширина контейнера `<ul>` - 400px;
- Между элементами списка должен быть вертикальный отступ 16px.
- Элементы списка должны быть разделены сплошной черной линией, толщина которой
  составляет 1px.

## Реализация

Страница `index.html` содержит заголовок и неупорядоченный список,
представляющий меню, каждый пункт которого разбит на два `<span>` - один для
блюда, другой для цены. В `styles.css` задается ширина меню в 400px. Пункты меню
построены на Flexbox (`display: flex`, `justify-content: space-between`,
`align-items: baseline`), чтобы название оставалось слева, цена прижималась к
правому краю, а строки выравнивались по базовой линии текста. Вертикальный
интервал между позициями задан через `padding: 8px 0` (в сумме `16px` между
соседними элементами), добавлен разделитель `1px solid black`.

## Запуск

Откройте `index.html` в браузере.
