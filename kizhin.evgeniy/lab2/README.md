# Лабораторная работа 2

## Задание

Создать функцию `isBalanced(str)`, проверяющую сбалансированность скобок
`()[]{}` в строке (например: `"{[()]}"` -> `true`, `"[(])"` -> `false`).

## Реализация

Решение оформлено в виде ES-модуля с экспортом функции `isBalanced(str)`. Для
проверки используется стек, словарь соответствия закрывающих скобок открывающим
и множество открывающих скобок. При проходе по символам строки открывающие
скобки добавляются в стек, а при встрече закрывающей проверяется, что стек не
пуст и его верхний элемент совпадает с парной открывающей скобкой; при
несовпадении возвращается `false`, а при совпадении верхний элемент снимается со
стека. По завершении цикла функция возвращает `true`, если стек пуст, иначе
`false`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
