# Лабораторная работа 3

## Задание

Реализуйте функцию `findPairsWithSum(arr, sum)`, которая возвращает все пары
чисел, дающие в сумме `sum`.

## Реализация

Функция `findPairsWithSum(arr, sum)` экспортируется как именованный экспорт
ES-модуля и перебирает пары элементов `(i, j)` с `j > i`, сохраняя порядок
встречи в `arr`. Если `arr[i] + arr[j] === sum`, пара `[arr[i], arr[j]]`
добавляется в результирующий массив; исходный массив не изменяется.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
