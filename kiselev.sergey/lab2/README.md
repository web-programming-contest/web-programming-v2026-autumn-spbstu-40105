# Лабораторная работа 2

## Задание

Вариант 37.Реализовать функцию formatPhoneNumber(phoneStr) для форматирования
строки телефона под шаблон "+7 (XXX) XXX-XX-XX"

## Реализация

Вход разбивается на группы цифр (3, 3, 2, 2) при помощи метода slice и
подставляется в шаблон `+7 (XXX) XXX-XX-XX`. Функция возвращает готовую строку.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
