# Курсовой проект: интернет-магазин Gadget Hub

## Задание

Веб-приложение интернет-магазина гаджетов, состоящее из двух частей, которые
запускаются на разных портах:

- `frontend` — React-приложение (Vite), `http://localhost:3000`;
- `backend` — REST API на Express, `http://localhost:8080`.

Страницы: главная (карусели хитов и новинок, преимущества, контакты), логин,
каталог (фильтры, сортировка, пагинация, pop-up товара) и корзина (оформление
заказа и история заказов). Каталог и корзина доступны только после входа.
Корзина хранится в `localStorage` и очищается после оформления заказа.

## Структура

```text
project/
├── backend/            # Express REST API
│   ├── data/           # goods.json, users.json, orders.json
│   └── src/
└── frontend/           # React + Vite
    ├── public/
    │   ├── fonts/      # шрифт Rubik
    │   └── images/     # товары, иконки, главная, логин, соцсети
    └── src/
        ├── api/        # запросы к бекенду
        ├── components/
        │   ├── cart/     # вкладки корзины, форма заказа, история
        │   ├── catalog/  # карточка, фильтры, пагинация, pop-up товара
        │   ├── home/     # карусели главной
        │   ├── icons/
        │   └── layout/   # шапка, подвал, логотип
        ├── context/    # авторизация и корзина
        ├── hooks/      # загрузка товаров и заказов
        ├── pages/
        └── utils/      # фильтрация/сортировка, валидация, форматирование
```

## Backend API

| Метод | Путь      | Назначение                                |
| ----- | --------- | ----------------------------------------- |
| POST  | `/login`  | Проверка логина и пароля, создание сессии |
| POST  | `/logout` | Завершение сессии                         |
| GET   | `/me`     | Текущий пользователь (проверка сессии)    |
| GET   | `/goods`  | Список всех товаров                       |
| GET   | `/orders` | Заказы текущего пользователя              |
| POST  | `/orders` | Создание нового заказа                    |

Данные хранятся в JSON-файлах в `backend/data`, чтение и запись асинхронные.

## Запуск

В двух терминалах:

```bash
cd kiselev.sergey/project/backend
npm install
npm run dev
```

```bash
cd kiselev.sergey/project/frontend
npm install
npm run dev
```

После этого открыть `http://localhost:3000`.
