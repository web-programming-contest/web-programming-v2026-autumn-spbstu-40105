# Лабораторная работа 5

## Задание

Вариант 37. Классическая игра "Крестики-нолики" с возможностью игры против
компьютера или другого игрока.

Функциональность:

- заставка (всё рабочее поле);
- экраны завершения игры.

## Реализация

Приложение собрано на React + Vite.

- `game.js` — правила: поиск победителя по восьми линиям, свободные клетки, чей
  сейчас ход;
- `ai.js` — ход компьютера: завершить свою линию, помешать сопернику, занять
  центр, иначе случайная клетка;
- `App.jsx` — состояние партии и сборка экрана;
- `components/` — `Board`, `Cell`, `SplashScreen`, `GameOverScreen`.

Поле хранится как массив из девяти клеток (`"X"`, `"O"` или `null`) и является
единственным состоянием партии — остальное вычисляется из него. Ход компьютера
выполняется в `useEffect` с задержкой, заставка и экран завершения показываются
условным рендером.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной и откройте
адрес из вывода Vite в браузере.
