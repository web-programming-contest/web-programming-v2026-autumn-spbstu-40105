# Лабораторная работа 3

## Задание

Вариант 12. Написать `zipArrays(...arrays)` для поэлементного объединения
массивов.

## Реализация

Функция из `solution.js` собирает элементы с одинаковыми индексами в новые
массивы. Исходные массивы не меняются. Если длины разные, используется длина
самого короткого массива. Без аргументов возвращается пустой массив.

## Запуск

Из корня репозитория выполнить `node`, затем:

```js
const {zipArrays} = await import('./kharlamov.kirill/lab3/solution.js');
zipArrays([1, 2], ['a', 'b']);
// [[1, 'a'], [2, 'b']]
```
