# Лабораторная работа 2

## Задание

Вариант 12. Написать функцию `formatPhoneNumber(phoneStr)`, которая переводит
строку из 10 цифр в формат `+7 (XXX) XXX-XX-XX`.

## Реализация

Функция находится в `solution.js`. Сначала проверяется входная строка, затем с
помощью `slice` номер разбивается на части и собирается в нужном формате.

## Запуск

В терминале из корня репозитория выполнить `node`, затем ввести:

```js
const {formatPhoneNumber} = await import('./kharlamov.kirill/lab2/solution.js');
formatPhoneNumber('9991234567');
// '+7 (999) 123-45-67'
```
