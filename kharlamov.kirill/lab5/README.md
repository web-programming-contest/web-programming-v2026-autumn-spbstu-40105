# Лабораторная работа 5

## Задание

Вариант 12. Сделать Тетрис на React: семь фигур, перемещение и поворот, падение
с ростом скорости, удаление полных рядов, очки и конец игры.

## Реализация

Правила игры находятся в `src/game.js`, интерфейс — в `src/main.jsx`. Поле
состоит из 20 строк и 10 колонок. Фигуры проверяются на столкновения с границами
и занятыми клетками. Полные строки удаляются после фиксации фигуры. Скорость
растёт за линии и время игры. Есть следующая фигура, пауза и новая игра.
Управление: стрелки, пробел для сброса, P для паузы или кнопки под полем.

## Запуск

В терминале перейти в каталог этой работы:

```powershell
npm.cmd install
npm.cmd run dev
```

Открыть адрес, показанный Vite. Игра начинается сразу. Для проверки сборки
выполнить `npm.cmd run build`. Папки `node_modules`, `dist` и lock-файлы в PR не
добавлять.
