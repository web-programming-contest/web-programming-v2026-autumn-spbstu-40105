# Лабораторная работа 4

## Задание

Вариант 12. Создать класс `ClothingItem`, функции обработки коллекции одежды и
интерфейс добавления и удаления товаров и цветов.

## Реализация

Класс и пять функций находятся в `model.js`, работа с интерфейсом — в `main.js`.
ID товаров уникальны, повторные цвета не добавляются. Изменения выполняются
через Promise и setTimeout. Список сохраняется в localStorage и
восстанавливается при открытии страницы. Внизу страницы можно выполнить каждый
из пяти запросов.

## Запуск

Открыть корень репозитория в VS Code. Запустить `index.html` через расширение
Live Server. Прямое открытие файла не подходит для загрузки ES-модулей.
