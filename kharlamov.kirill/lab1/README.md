# Лабораторная работа 1

## Задание

Вариант 12. Сделать макет страницы с шапкой, боковой панелью шириной 300px,
основным контентом и футером. У каждого блока должен быть свой фон и чёрная
рамка 1px.

## Реализация

Разметка находится в `index.html`, стили — в `styles.css`. Для расположения
блоков используется Grid. Основной контент занимает оставшееся место. На узком
экране блоки располагаются друг под другом.

## Запуск

Открыть `index.html` в браузере.
