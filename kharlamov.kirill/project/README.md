# Gadget Hub

Курсовой проект по дисциплине «Web-разработка». Интернет-магазин гаджетов с
каталогом, корзиной, оформлением и историей заказов.

Курсовой проект выполнен совместно с Мезенцевым Антоном Андреевичем.

## Запуск

Нужен Node.js 22 или новее. Откройте папку проекта в VS Code и выполните в
терминале:

```powershell
node start.mjs
```

Откройте **http://127.0.0.1:3000**. Фронтенд слушает порт **3000**, REST API —
порт **8080**. Остановить оба сервера можно через Ctrl+C. Установка npm-пакетов
для проекта не требуется.

Можно запустить серверы по отдельности из корня проекта. В первом терминале
выполните `node backend/server.mjs`, во втором — `node frontend/server.mjs`.

Учебная учётная запись — **demo**, пароль — **gadget123**. Для проверки формы
используйте вымышленные контактные данные.

## Демонстрация

1. На главной прокрутите карусели хитов и новинок.
2. Перейдите в каталог без входа. Откроется форма авторизации. Проверьте пустые
   поля и неправильный пароль, затем войдите с учебной учётной записью.
3. В каталоге выберите сортировку, примените фильтры цены, типа и цвета.
   Сбросьте фильтры и перейдите на другую страницу.
4. Откройте товар, добавьте его в корзину, измените количество в модальном окне
   и закройте окно клавишей Esc. Обновите страницу, чтобы проверить сохранение
   количества.
5. Зайдите в корзину. Проверьте подтверждение удаления отдельного или нескольких
   товаров. Для оформления оставьте хотя бы один товар.
6. Нажмите «Оформить заказ» с пустыми полями. Затем задайте телефон, способ
   оплаты и, при выборе доставки, адрес. Оформите заказ.
7. Откройте вкладку «История заказов». Сверьте номер и стоимость со свежей
   записью в `backend/data/orders.json`. Выйдите из системы и повторите попытку
   открыть каталог.

Чекбоксы в корзине выбирают позиции для массового удаления. При оформлении в
заказ уходят все позиции корзины.

### Дополнение «Собрать комплект»

После входа откройте каталог и нажмите «Собрать комплект». Для сценария «В
дорогу» введите 10 000 ₽. Подбор предложит внешний аккумулятор и наушники за 9
480 ₽. С бюджетом 6 000 ₽ появится минимальная стоимость доступного комплекта.

Всего есть 13 готовых сценариев.

| Раздел               | Сценарии                                                                       |
| -------------------- | ------------------------------------------------------------------------------ |
| Дорога и прогулки    | В дорогу, в длительную поездку, на пикник                                      |
| Спорт и самочувствие | На тренировку, для ежедневной активности                                       |
| Связь и работа       | Новый смартфон с аксессуарами, для удалённой работы, для цифровой безопасности |
| Съёмка и запись      | Для записи видео, для озвучки и подкаста                                       |
| Дом и отдых          | Для уютного вечера, для зоны виртуальной реальности, небольшой подарок         |

В режиме «Свой комплект» можно выбрать от двух до четырёх разных типов товаров
из каталога. Для показа на защите попробуйте комплект из портативной акустики,
внешнего аккумулятора и умной лампы.

В готовом сценарии все позиции отмечены по умолчанию. Снимите галочку с ненужной
позиции, например «Подзарядка в пути» в сценарии «В дорогу». Можно оставить одну
позицию. Если результат уже показан, он пересчитается сразу, включая минимальную
стоимость и остаток бюджета.

Для каждой отмеченной роли или выбранного типа берётся по одному товару.
Алгоритм перебирает комбинации разных товаров, находит минимальную стоимость и
среди вариантов в пределах бюджета выбирает комплект с наибольшей суммой
показателей популярности. При равной популярности выбирает более дешёвый
комплект. Кнопка добавления увеличивает количество каждого товара на одну
единицу. Если у любой позиции достигнут лимит в 99 единиц, вся корзина сохраняет
прежнее состояние.

## Устройство проекта

| Файл                                         | Назначение                                                                        |
| -------------------------------------------- | --------------------------------------------------------------------------------- |
| `frontend/index.html`, `frontend/styles.css` | Общая разметка, стили страниц и модальных окон                                    |
| `frontend/app.js`                            | Карусели, формы, фильтрация, сортировка, пагинация, корзина и запросы к API       |
| `frontend/bundle.js`                         | Сценарии и алгоритм подбора комплектов в пределах общего бюджета                  |
| `frontend/server.mjs`                        | Локальный сервер страниц и статических файлов                                     |
| `backend/server.mjs`                         | REST API, сессии, валидация и запись заказов                                      |
| `backend/data/goods.json`                    | 32 товара с фотографиями из материалов курса и демонстрационными характеристиками |
| `backend/data/orders.json`                   | История заказов. Начальное состояние — пустой массив                              |
| `start.mjs`                                  | Запуск обоих серверов                                                             |

| Метод и путь                  | Назначение                                    |
| ----------------------------- | --------------------------------------------- |
| `GET /featured`               | Хиты и новинки для публичной главной страницы |
| `GET /session`                | Получение текущего пользователя               |
| `POST /login`, `POST /logout` | Вход и завершение сессии                      |
| `GET /goods`                  | Каталог после входа                           |
| `GET /orders`, `POST /orders` | История пользователя и оформление заказа      |

Сервер авторизации выдаёт сессионную cookie с флагом HttpOnly. Фронтенд
отправляет её с запросами к API на другом порту. При перезапуске сервера
выполняется повторный вход, а записи о заказах сохраняются на диске.

Корзина хранит идентификаторы и количества в `localStorage` под ключом
пользователя. При оформлении сервер проверяет товары и вычисляет итог по своим
ценам. Список покупок очищается после успешного ответа. Записи заказов
выполняются последовательно, а новый JSON заменяет предыдущий после записи
временного файла.

Оформление опирается на макеты Gadget Hub, фотографии и иконки из архива курса,
шрифт Rubik из того же архива. Контакты, ссылки на соцсети и товарные
характеристики используются для демонстрации.

## Подготовка к защите вдвоём

Возможное распределение для совместной доработки и защиты:

- Первый участник ведёт клиентскую часть. Показывает маршруты, карусели,
  фильтры, карточки и изменение корзины.
- Второй участник ведёт серверную часть. Показывает сессию, REST-запросы,
  проверку заказа и запись в JSON.
- Вместе прогоните сценарий выше. На защите расскажите о фактическом вкладе
  каждого и объясните, как данные переходят из корзины в заказ. На защите
  присутствуют оба автора.
