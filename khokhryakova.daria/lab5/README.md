# Лабораторная работа 5

## Задание

Вариант 16. Создать приложение прогноза погоды на React.

Функциональность:

- отображение текущей погоды с основными показателями (температура, состояние,
  влажность, ветер);
- возможность сменить город через форму;
- переключение интервала прогноза (1, 3 или 7 дней).

## Реализация

Приложение на React с использованием Vite. Вся логика — в компоненте `App`,
данные о погоде хранятся локально в `src/weather.js` (без обращения к внешнему
API). Состояние управляется через `useState`.

Публичные селекторы:

- `[data-testid="app"]` — корневой элемент приложения;
- `[data-testid="weather-city"]` — поле ввода города;
- `[data-testid="weather-submit"]` — кнопка отправки формы;
- `[data-testid="weather-current"]` — блок текущей погоды;
- `[data-testid="weather-forecast"]` — блок прогноза.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
