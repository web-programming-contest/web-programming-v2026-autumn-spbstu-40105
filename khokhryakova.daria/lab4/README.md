# Лабораторная работа 4

## Задание

Вариант 16. Рестораны и меню.

Создать класс `Restaurant` с полями `name` (название ресторана) и `menu` (массив
блюд, каждое с полями `name` и `price`). Реализовать методы:

- `addDish(dish)` — добавить блюдо;
- `removeDish(dishName)` — удалить блюдо по имени;
- геттер `menuSize` — количество блюд.

Реализовать функции:

- `groupRestaurantsByMenuSize` — группировка ресторанов по количеству блюд;
- `getUniqueDishes` — уникальный список всех блюд;
- `findRestaurantsByDish` — рестораны с заданным блюдом;
- `groupDishesByPriceRange` — группировка блюд по ценовым диапазонам;
- `findRestaurantsWithMostExpensiveDish` — рестораны с самым дорогим блюдом.

Реализовать UI: карточки ресторанов с названием, меню и количеством позиций.
Формы создания ресторана и добавления блюда, кнопки добавления и удаления. Все
операции добавления и удаления выполняются асинхронно через `Promise` +
`setTimeout`. Состояние сохраняется в `localStorage`.

## Реализация

Модель — в `model.js`: класс `Restaurant` и пять функций экспортируются
именованно. UI — в `main.js`: рендер карточек, обработка форм, асинхронные
операции через `Promise` + `setTimeout`, сохранение в `localStorage`.

DOM-контракт:

- `[data-testid="entity-list"]` — список ресторанов;
- `form[data-testid="entity-form"]` — форма добавления ресторана;
- `[data-testid="entity-card"]` — карточка ресторана;
- `[data-testid="delete-entity"]` — кнопка удаления внутри карточки.

## Запуск

Открыть `index.html` в браузере.
