# Лабораторная работа 1

## Задание

Вариант 28. Создать базовый макет веб-страницы, содержащий заголовок, боковую
панель, основную часть с контентом и футер. Для верстки использовать Grid.
Боковая панель должна иметь фиксированную ширину 300px, а основной контент
должен занимать все оставшееся свободное пространство. Каждый элемент макета
должен иметь цвет фона, отличающийся от других элементов, и черную рамку шириной
1px.

## Реализация

Для создания макета использована технология CSS Grid Layout. Контейнер `.layout`
разделен на две колонки: первая фиксированная (300px) для сайдбара, вторая
гибкая (`1fr`) для основного контента. С помощью свойства `grid-template-areas`
определены зоны для Header, Sidebar, Content и Footer. Каждому блоку задан
уникальный фоновый цвет и общая черная рамка толщиной 1px. Inline-стили
отсутствуют, разметка семантическая.

## Запуск

Откройте файл `index.html` в любом современном браузере.
