# Лабораторная работа 2

## Задание

Вариант 28. Написать функцию `calculateExpression(expr)`, вычисляющую значение
математического выражения в строке. Например, для `"2 + 3 * 4"` результат равен
`14`.

## Реализация

Файл `solution.js` является ES-модулем и содержит именованный экспорт
`calculateExpression`. Функция синхронно возвращает число.

Выражение разбирается последовательно с помощью трёх функций:

- `parseExpression` обрабатывает сложение и вычитание;
- `parseTerm` обрабатывает умножение и деление;
- `parseFactor` читает число, знак перед числом или выражение в скобках.

Такой порядок обеспечивает приоритет умножения и деления над сложением и
вычитанием. Операции одинакового приоритета выполняются слева направо.
Пробельные символы между элементами выражения пропускаются.

Дополнительно поддерживаются отрицательные числа, скобки и дробные числа с
точкой. При неправильном типе аргумента, ошибке синтаксиса, делении на ноль или
непредставимом конечным числом результате выбрасывается исключение. Вычисления
используют стандартный тип `Number` JavaScript и его точность. `eval` и
`Function` не используются. При импорте файл ничего не выводит в консоль.

## Запуск

Импортируйте именованный export из solution.js как ES module.
