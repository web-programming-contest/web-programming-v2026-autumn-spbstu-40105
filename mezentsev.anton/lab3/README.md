# Лабораторная работа 3

## Задание

Вариант 28. Реализовать функцию `findMostFrequent(arr)`, которая возвращает
самый часто встречающийся элемент в массиве.

Например, для `[1, 2, 2, 3, 2, 1]` результат равен `2`.

## Реализация

Файл `solution.js` является ES-модулем и содержит именованный экспорт
`findMostFrequent`. Функция синхронно возвращает найденный элемент и не изменяет
исходный массив. При импорте файл ничего не выводит в консоль.

Алгоритм состоит из двух проходов:

1. Подсчитать частоту каждого элемента с помощью `Map`.
2. Пройти по полученным частотам и выбрать элемент с максимальным количеством
   вхождений.

Сравнение ключей выполняется по правилам `Map`: число `1` и строка `'1'`
считаются разными элементами, а объекты сравниваются по ссылке.

Для случаев, не уточнённых в задании, приняты следующие решения:

- если несколько элементов имеют одинаковую максимальную частоту, возвращается
  тот, который первым встретился в исходном массиве;
- для пустого массива возвращается `undefined`.

Ожидаемая временная сложность — `O(n)`, дополнительная память — `O(k)`, где `n`
— длина массива, а `k` — количество различных элементов.

## Запуск

Импортируйте именованный export из solution.js как ES module.
