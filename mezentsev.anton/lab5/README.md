# Лабораторная работа 5

## Задание

Вариант 28. Реализовать компонент списка книг в виде дерева с возможностью
скрывать и раскрывать ветки. Уровни: автор → издательство → жанр → название
книги. Согласно требованиям репозитория курса приложение реализовано на React.

## Реализация

- `index.html` — HTML-страница с подключением точки входа.
- `src/main.jsx` — компоненты `App` и рекурсивный `TreeNode`.
- `src/data.js` — локальные данные, построение дерева и получение ID веток.
- `src/styles.css` — оформление и адаптация под мобильные экраны.
- `package.json` — зависимости React, React DOM, Vite и команды сборки.

Каталог содержит девять книг трёх авторов. Названия издательств условные.
Функция `buildTree` группирует плоский список сначала по автору, затем по
издательству и жанру, используя `Map`. Последний уровень содержит названия книг.
Пустой список преобразуется в пустое дерево. Исходный массив не изменяется. ID
веток строятся из полного пути, поэтому одинаковые жанры разных авторов
переключаются независимо. Книги имеют собственные уникальные ID.

Компонент `TreeNode` рекурсивно выводит вложенные списки. Для веток он создаёт
кнопку, а для книг — текстовый элемент. В `App` хранится `Set` раскрытых веток
через `useState`. При переключении создаётся новый `Set`, после чего React
обновляет интерфейс. Изначально все ветки раскрыты, поэтому видны четыре уровня.
Кнопки «Раскрыть всё» и «Свернуть всё» управляют всей коллекцией.

Скрытие родительской ветки сохраняет состояние дочерних веток до перезагрузки
страницы. Сохранение в `localStorage` для этого задания не требуется и не
реализовано: после перезагрузки дерево снова полностью раскрыто.

Для доступности используются обычные вложенные списки и кнопки с `aria-expanded`
и `aria-controls`; скрытые списки имеют атрибут `hidden`. Кнопки доступны через
Tab и переключаются клавишами Enter и Space. Не используется ARIA-роль `tree`,
требующая отдельной навигации стрелками.

Публичные селекторы курса: `app` на `main`, `tree` на корневом списке,
`tree-toggle` на кнопках веток, `tree-branch` на вложенных списках, `tree-level`
на узлах каждого из четырёх уровней. Все данные и стили локальные, приложение не
обращается к внешним API или CDN.

## Запуск

Используйте Node.js 24.19.0, указанный в README курса, и npm. Поместите папку
`lab5` в свой каталог `surname.name` репозитория курса. Замените `surname.name`
фамилией и именем латиницей в нижнем регистре.

В терминале из каталога лабораторной выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который Vite напечатает в терминале (обычно
`http://127.0.0.1:5173`). Не открывайте HTML двойным щелчком: JSX требует
сборки. Для остановки сервера нажмите Ctrl+C в терминале.

Проверка производственной сборки:

```bash
npm run build
npm run preview
```

Проверка интерфейса:

1. Убедитесь, что видны все четыре уровня и названия книг.
2. Сверните первого автора: его издательства, жанры и книги должны исчезнуть.
3. Раскройте автора повторно и отдельно сверните издательство или жанр.
4. Проверьте кнопки «Свернуть всё» и «Раскрыть всё».
5. Переключите ветку с клавиатуры и проверьте страницу на узком экране.

Из корня репозитория курса выполните:

```bash
npm run format -- surname.name/lab5
npm run format:check -- surname.name/lab5
npm run lint:js -- surname.name/lab5
npm run lint:css -- "surname.name/lab5/**/*.css"
npm run lint:html -- "surname.name/lab5/**/*.html"
```

Не добавляйте в PR созданные локально `node_modules`, `dist` и lock-файлы.
Название отдельного PR: `[TASK-5] variant_28 surname.name`.
