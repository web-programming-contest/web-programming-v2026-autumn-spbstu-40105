# Лабораторная работа 4

## Задание

Вариант 28. Создать модель фильма с названием, режиссёром и списком актёров,
функции работы с коллекцией и пользовательский интерфейс фильмотеки. Добавление
и удаление выполнять асинхронно через `Promise` и `setTimeout`. Сохранять
коллекцию в `localStorage` и восстанавливать после перезагрузки. Упоминание
списка студентов в пункте 4.3 методички трактуется как опечатка: в этой работе
сохраняются фильмы и их актёры.

## Реализация

- `model.js` — независимая от браузера модель и функции коллекций.
- `main.js` — формы, карточки, асинхронные операции и хранение данных.
- `index.html` — семантическая разметка и подключение ES-модуля.
- `styles.css` — оформление и адаптация для узких экранов.

Класс экспортируется как `Movie` согласно публичному контракту курса.
Конструктор: `new Movie(title, director, actors = [])`. Массив актёров
копируется. Метод `addActor(name)` добавляет имя, `removeActor(name)` удаляет
все совпадения по точному имени, геттер `castSize` возвращает актуальную длину
списка. В интерфейсе повторное добавление одного имени в фильм запрещено.

Именованные экспорты функций:

| Функция                            | Результат                             |
| ---------------------------------- | ------------------------------------- |
| `groupMoviesByDirector(movies)`    | `Map`: режиссёр → массив фильмов      |
| `getUniqueActors(movies)`          | Массив уникальных имён актёров        |
| `groupMoviesByCastSize(movies)`    | `Map`: число актёров → массив фильмов |
| `findMoviesByActor(movies, actor)` | Массив фильмов с указанным актёром    |
| `getMovieTitles(movies)`           | Массив названий фильмов               |

Функции не изменяют входную коллекцию. Поиск учитывает регистр и полное имя.
Пустая коллекция возвращает пустые массивы или `Map`. Все пять функций
используются в разделе «Обзор коллекции».

Изменения выполняются после задержки 300 мс через `Promise` и `setTimeout`. На
время операции кнопки блокируются. После изменения интерфейс обновляется без
перезагрузки, данные записываются под ключом `lab4-variant28-movies`. При
загрузке из JSON восстанавливаются экземпляры `Movie` с методами и геттером.
Пустая коллекция также сохраняется. Ошибки чтения или записи показываются
пользователю. Пользовательские строки выводятся через `textContent`.

Присутствуют обязательные атрибуты `data-testid`: `entity-list`, `entity-form`,
`entity-card`, `delete-entity`. Поля основной формы имеют имена `title` и
`director`. Внешних ресурсов и зависимостей нет.

## Запуск

```bash
python -m http.server 8000
```

Откройте в браузере `http://localhost:8000`. Открывать HTML двойным щелчком
через `file://` не следует: браузер может заблокировать импорты ES-модулей.

Проверка вручную:

1. Добавьте фильм, указав название и режиссёра.
2. Добавьте двух актёров: список и число актёров должны обновиться.
3. Проверьте варианты обзора коллекции и поиск по полному имени актёра.
4. Перезагрузите страницу: фильм и актёры должны сохраниться.
5. Удалите актёра, затем фильм и снова перезагрузите страницу.
