# Курсовой проект: интернет-магазин Gadget Hub

## Задание

Веб-приложение интернет-магазина гаджетов, состоящее из двух независимых частей,
запускаемых на разных портах:

- **Frontend:** React + Vite + TypeScript + Zustand (порт `3000`).
- **Backend:** REST API на Go с использованием фреймворка Echo (порт `8080`).

- Главная страница с каруселями хитов и новинок.
- Система аутентификации (валидация полей, обработка ошибок, защита маршрутов).
- Каталог товаров с фильтрацией (цена, категория, цвет), сортировкой, пагинацией
  и модальным окном товара.
- Корзина с сохранением состояния в `localStorage`, формой оформления заказа и
  историей покупок.

## Backend API

| Метод | Путь      | Назначение                                |
| ----- | --------- | ----------------------------------------- |
| POST  | `/login`  | Проверка логина и пароля, создание сессии |
| POST  | `/logout` | Завершение сессии                         |
| GET   | `/me`     | Текущий пользователь (проверка сессии)    |
| GET   | `/goods`  | Список всех товаров                       |
| GET   | `/orders` | Заказы текущего пользователя              |
| POST  | `/orders` | Создание нового заказа                    |

