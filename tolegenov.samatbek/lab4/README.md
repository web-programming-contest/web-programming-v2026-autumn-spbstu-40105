# Лабораторная работа 4

## Задание

Задача 4. 4.1. Создать класс ClothingItem с полями: • id — уникальный номер
(число) • name — название товара (строка) • size — размер (строка: S, M, L, XL)
• colors — массив доступных цветов (строки) Реализовать методы: •
addColor(color) — добавить цвет 112 • removeColor(color) — удалить цвет • геттер
colorsCount — количество цветов 4.2. Дан массив товаров: • Реализовать функцию
для группировки товары по размеру • Реализовать функцию возвращающий список всех
уникальных цветов • Реализовать функцию, возвращающий товары, доступные в
заданном цвете • Реализовать функцию, группирующий товары по количеству
доступных цветов • Реализовать функцию возвращающий товары, доступные в более
чем N цветах 4.3 Реализовать пользовательский интерфейс: • Список карточек
карточек товаров. В каждой карточке указывать: название, размер, список цветов,
количество цветов • Кнопки: "Добавить цвет", “Удалить цвет”, “Добавить товар”,
"Удалить товар" • Форма создания товара (ID, название, размер). Форма добавления
цвета • При любых изменениях автоматически обновлять пользовательский интерфейс
• Все операции добавления/удаления выполнять асинхронно через Promise

- setTimeout() • Использовать local storage для сохранения текущего списка
  студентов при закрытии вкладки.

## Реализация

**Файлы:**

- `index.html` — разметка
- `styles.css` — стили
- `model.js` — класс, функции над массивом, хранилище (без работы с DOM)
- `main.js` — интерфейс и обработчики событий

**model.js**

- `ClothingItem`: цвета приводятся к нижнему регистру и обрезаются по пробелам,
  дубликаты и пустые значения не добавляются (выбрасывается ошибка).
- Функции 4.2: `groupBySize`, `getUniqueColors`, `getItemsByColor`,
  `groupByColorsCount`, `getItemsWithMoreColors`.
- `delay` и `runAsync` — задержка 400 мс через `Promise` и `setTimeout`.
- `catalog` — хранение списка в `localStorage`, при пустом хранилище загружаются
  5 товаров по умолчанию.

**main.js**

- `render()` перерисовывает карточки после каждого изменения.
- `perform()` выполняет операцию асинхронно, блокирует кнопки на время
  выполнения, сохраняет данные и показывает сообщение или ошибку.
- Проверки при добавлении товара: ID целый и больше 0, название не пустое,
  размер из списка, ID уникален.
- Блок «Анализ каталога» выводит результаты функций из 4.2.

## Запуск

Откройте `index.html` в браузере.
