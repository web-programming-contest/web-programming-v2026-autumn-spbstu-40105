# Лабораторная работа 2

## Задание

Вариант 37.Реализовать функцию formatPhoneNumber(phoneStr) для форматирования
строки телефона под шаблон "+7 (XXX) XXX-XX-XX"

## Реализация

1. Входное значение приводится к строке (`String(phoneStr)`) и из неё удаляются
   все нецифровые символы (`replace(/\D/g, '')`): пробелы, скобки, дефисы, плюс
2. Если цифр 11 и номер начинается с `7` или `8`, первая цифра отбрасывается как
   код страны
3. Если после этого цифр не 10, выбрасывается ошибка
   `Error('Некорректный номер телефона')`
4. Десять цифр разбиваются регулярным выражением на группы 3-3-2-2 и
   подставляются в шаблон `+7 ($1) $2-$3-$4`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
