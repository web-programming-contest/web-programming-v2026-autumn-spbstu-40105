# Лабораторная работа 5

## Задание

Вариант 21. Реализовать FAQ-аккордеон на React. Ответы должны плавно
раскрываться и сворачиваться. Пользователь может выбрать режим с одним открытым
ответом или режим, в котором можно открыть несколько ответов.

## Реализация

В `src/main.jsx` компонент `App` хранит список открытых вопросов и текущий
режим, а `FaqItem` отображает кнопку вопроса и панель ответа. По умолчанию
открытие нового ответа закрывает предыдущий. Флажок позволяет открывать ответы
независимо. При возврате в одиночный режим остаётся последний открытый ответ.
Кнопки поддерживают управление клавиатурой.

В `src/styles.css` высота строки CSS Grid меняется между `0fr` и `1fr` за 250
мс. При сворачивании панель скрывается после завершения перехода. Системная
настройка уменьшения движения отключает анимацию.

## Запуск

Из каталога `bocharov.egor/lab5` выполните:

```powershell
npm install --no-package-lock
npm run dev -- --host 127.0.0.1
```

Откройте адрес из строки `Local` в выводе Vite. Для проверки сборки выполните
`npm run build`.
