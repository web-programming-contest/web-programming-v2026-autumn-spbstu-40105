# Лабораторная работа 3

## Задание

Вариант 21. Реализовать функцию `findMaxSubarraySum(arr, n)`, которая находит
максимальную сумму подмассива длины `n`.

## Реализация

Экспортируется функция `findMaxSubarraySum(arr, n)`. Она принимает массив чисел
`arr` и целое число `n` и возвращает наибольшую сумму `n` подряд идущих
элементов. Используется метод скользящего окна: сначала считается сумма первых
`n` элементов, затем окно сдвигается на один элемент, при этом к сумме
прибавляется вошедший элемент и вычитается вышедший. Лучшая сумма обновляется на
каждом шаге. Это даёт один проход по массиву, то есть линейное время. Граничные
случаи: если `arr` не является массивом чисел или `n` не целое число,
выбрасывается `TypeError`; если `n` меньше 1 или больше длины массива,
выбрасывается `RangeError`. Отрицательные числа обрабатываются корректно, так
как начальный максимум равен сумме первого окна.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {findMaxSubarraySum} from './solution.js';

console.log(findMaxSubarraySum([2, 1, 5, 1, 3, 2], 3)); // 9
```
