# Лабораторная работа 4

## Задание

Вариант 21. Создать класс `Recipe` с полями `title` (название), `ingredients`
(массив ингредиентов) и `steps` (массив шагов) и методами `addIngredient`,
`removeIngredient`, геттером `ingredientCount`. Реализовать функции над массивом
рецептов: группировка по количеству ингредиентов, уникальный список
ингредиентов, поиск рецептов по ингредиенту, группировка по длине списка шагов,
список названий. Реализовать интерфейс: карточки рецептов, кнопки добавления и
удаления ингредиентов, шагов и рецептов, форма нового рецепта. Все операции
изменения выполняются асинхронно через `Promise` и `setTimeout()`, список
автоматически перерисовывается, данные сохраняются в `localStorage`.

## Реализация

`model.js` содержит класс `Recipe` и функции коллекции:
`groupRecipesByIngredientCount`, `getUniqueIngredients`,
`findRecipesByIngredient`, `groupRecipesByStepCount`, `getRecipeTitles`.
Группировки возвращают `Map`, где ключ — число, а значение — массив рецептов.
`main.js` хранит рецепты в массиве, при каждом изменении выполняет операцию
через `Promise` с задержкой `setTimeout` (300 мс), затем сохраняет данные в
`localStorage` (ключ `lab4-variant21-recipes`) и перерисовывает карточки. Кнопки
внутри карточек обрабатываются одним обработчиком на списке. Ошибки (пустое
название, отсутствующий ингредиент или шаг) показываются в строке состояния.
Раздел «Обзор коллекции» показывает результаты функций из `model.js`.

## Запуск

Страница использует ES-модули, поэтому её нужно открывать через локальный
сервер, например `python -m http.server 8000` в папке `lab4` и адрес
`http://localhost:8000`, либо расширение Live Server для VS Code.
