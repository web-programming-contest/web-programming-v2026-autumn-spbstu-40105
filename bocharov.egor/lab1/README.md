# Лабораторная работа 1

## Задание

Вариант 21. Создать горизонтальное меню навигации, которое при ширине экрана
менее 768px меняет свою структуру и превращается в вертикальное меню.

## Реализация

Меню оформлено как список ссылок `ul` внутри элемента `nav`. По умолчанию список
выводится в строку через `display: flex`. Для экранов уже 768px сработает
медиазапрос `@media (width < 768px)`, где у списка задано
`flex-direction: column`, и пункты выстраиваются в столбец. Ссылки ведут на
разделы страницы по якорям. При наведении курсора цвет фона пункта меняется.

## Запуск

Откройте `index.html` в браузере. Чтобы проверить адаптивность, уменьшите ширину
окна браузера меньше 768px: меню станет вертикальным.
