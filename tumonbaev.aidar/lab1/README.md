# Лабораторная работа 1

## Задание

Создать постраничную навигацию (пагинацию). Требования варианта 5:

- элементы навигации расположены по центру страницы;
- текст внутри элемента навигации выровнен по центру по двум осям;
- фон активного элемента навигации отличается от остальных;
- фон элементов навигации изменяется при наведении.

## Реализация

Навигация реализована как семантический элемент `<nav>` со списком `<ul>`,
внутри которого каждая страница — кнопка `<button>`. Активная страница помечена
классом `pagination__link--active` и атрибутом `aria-current="page"`. Стрелки
«назад»/«вперёд» имеют `aria-label` для доступности.

Центрирование по обеим осям — flexbox на `body` и `.pagination__list`. Изменение
фона при наведении реализовано через `:hover`, состояние фокуса — через
`:focus-visible`.

## Запуск

Открыть файл `index.html` в браузере — сборка не требуется.
