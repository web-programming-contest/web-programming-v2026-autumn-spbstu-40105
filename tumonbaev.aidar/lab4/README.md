# Лабораторная работа 4

## Задание

Вариант 5. Класс `Team` (название команды и массив участников с именем и ролью)
с методами `addMember`, `removeMember` и геттером `memberCount`. Функции над
массивом команд: группировка участников по ролям, уникальные роли, группировка
команд по количеству участников, поиск команд по имени участника, список всех
участников без повторов. Интерфейс: карточки команд, добавление и удаление
команд и участников, асинхронные операции через Promise и setTimeout, сохранение
состояния в localStorage.

## Реализация

Модель вынесена в `model.js`: класс `Team` и функции работы с коллекцией,
которые не изменяют входной массив. В `main.js` хранится массив команд, любая
операция выполняется через Promise и setTimeout, после чего состояние
сохраняется в localStorage, а интерфейс перерисовывается. При загрузке данные
восстанавливаются из localStorage.

## Запуск

Модули ES требуют HTTP-сервера, поэтому страницу нужно открывать через локальный
сервер, например командой npx serve в каталоге лабораторной, либо через
расширение Live Server в VS Code.
