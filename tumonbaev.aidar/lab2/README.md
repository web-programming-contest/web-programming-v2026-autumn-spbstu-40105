# Лабораторная работа 2

## Задание

Написать функцию `toBinary(num)`, преобразующую десятичное число в двоичную
строку (без ведущих нулей).

## Реализация

Функция экспортируется именованно из `solution.js` как ES module. Используется
встроенный метод `Number.prototype.toString(2)`, который сам по себе не
добавляет ведущих нулей. Отдельно обрабатываются случаи нуля (возвращается
`"0"`) и отрицательных чисел (знак `-` добавляется перед двоичным представлением
модуля числа).

## Запуск

Функция — чистый ES module, сборка не требуется. Пример использования:

\`\`\`js import { toBinary } from './solution.js';

toBinary(10); // '1010' toBinary(0); // '0' toBinary(-5); // '-101' \`\`\`
