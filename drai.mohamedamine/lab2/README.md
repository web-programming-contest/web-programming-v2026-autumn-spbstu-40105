# Лабораторная работа 2

## Задание

Вариант 7. Написать функцию `findLongestPalindrome(str)`, которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Экспортируется функция `findLongestPalindrome`. Используется алгоритм расширения
вокруг каждого символа и пары соседних символов как центров палиндрома для
поиска самой длинной палиндромной подстроки. Функция корректно обрабатывает
граничные случаи (пустая строка, одиночные символы) и возвращает найденную
подстроку.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
