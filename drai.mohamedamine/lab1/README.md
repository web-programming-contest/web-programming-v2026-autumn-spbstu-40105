# Лабораторная работа 1

## Задание

Вариант 7: Создать три карточки товара. Каждая карточка должна быть представлена
div-блоком, содержащим:

- Изображение (размер 200px на 150px);
- Заголовок (шрифт Arial, размер 18px, жирный стиль);
- Описание (шрифт Arial, размер 14px).

Карточки должны располагаться в одну строку (горизонтально) с отступом 20px
между ними. Для всех элементов используйте padding: 10px.

## Реализация

Создана HTML-страница с тремя карточками товаров. Каждая карточка содержит
изображение, заголовок и описание. Карточки расположены горизонтально с отступом
20px с использованием CSS Flexbox. Для всех элементов применен padding: 10px.

## Запуск

Откройте файл index.html в любом современном браузере.
