# Лабораторная работа 5

## Задание

Задача 5. Сортировка книг в книжном интернет-магазине (`book-sorting`).

Список книг, где у каждой книги есть обложка, название, рейтинг, описание и
цена. Над списком находятся кнопки «Название», «Цена» и «Рейтинг». Нажатая
кнопка выделяется цветом и показывает стрелку текущего порядка (↑ или ↓), а
книги выводятся в отсортированном виде. Порядок сортировки по кругу: по
возрастанию, по убыванию, не задано (исходный порядок).

## Реализация

Приложение написано на React 18 и собирается Vite.

- `src/books.js` — исходные данные книг, обложки лежат в `assets/` и
  подключаются как модули.
- `src/sorting.js` — чистые функции: `getNextSort` переключает порядок по кругу,
  `sortBooks` возвращает новый отсортированный массив и не изменяет исходный.
  Названия сравниваются через `localeCompare` с локалью `ru`, при равенстве
  значений книги остаются в исходном порядке.
- `src/components/SortBar.jsx` — кнопки сортировки (`data-testid` `sort-title`,
  `sort-price`, `sort-rating`) и строка состояния `sort-direction`.
- `src/components/BookCard.jsx` — карточка книги (`data-testid` `book-card`).
- `src/App.jsx` — состояние сортировки `{key, direction}` и вывод списка.

Активная кнопка получает класс `is-active`, цвет фона и `aria-pressed`. Все
данные и изображения локальные, обращений во внешнюю сеть нет.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной. Для сборки
используйте `npm run build`.
