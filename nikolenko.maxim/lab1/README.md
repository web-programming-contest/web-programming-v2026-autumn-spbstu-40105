# Лабораторная работа 1

## Задание

Создать форму регистрации по образцу из задания. Форма должна удовлетворять
следующим требованиям:

- ширина формы — 400px;
- внутренний отступ — 8px;
- цвет кнопки — `#0056ff`;
- цвет кнопки при наведении курсора — `#417ffb`.

Форма состоит из пяти полей ввода с подсказками (placeholder) «Имя», «E-mail»,
«Телефон», «Пароль», «Пароль еще раз» и кнопки «Регистрация», которая занимает
всю ширину формы.

## Реализация

Решение состоит из двух файлов:

- `index.html` — семантическая разметка страницы: форма `<form>` с пятью
  элементами `<input>` и кнопкой `<button type="submit">`. Для каждого поля
  заданы подходящий `type` (`text`, `email`, `tel`, `password`), атрибуты `name`
  и `placeholder`. Стили подключаются через `styles.css`, inline-стили не
  используются.
- `styles.css` — оформление формы. Классы названы в kebab-case, ID-селекторы и
  `!important` не используются.

Основные решения:

- ширина формы задана как `width: 400px`, внутренний отступ — `padding: 8px`;
- для корректного расчёта размеров используется `box-sizing: border-box`,
  поэтому поля и кнопка занимают всю доступную ширину формы без горизонтального
  переполнения;
- поля ввода расположены друг под другом с одинаковыми вертикальными
  интервалами;
- цвет кнопки `#0056ff` задан в основном состоянии, при наведении курсора
  (`:hover`) меняется на `#417ffb`;
- для кнопки и полей предусмотрено видимое состояние фокуса (`:focus-visible`),
  чтобы форма была удобна при работе с клавиатуры.

## Запуск

Для запуска не требуется сборка или установка зависимостей. Откройте файл
`index.html` в любом современном браузере, например двойным щелчком по файлу или
через команду из корня репозитория:

```
open surname.name/lab1/index.html
```

Для проверки форматирования и стиля кода из корня репозитория выполните:

```
npm run format:check -- surname.name/lab1
npm run lint:css -- "surname.name/lab1/**/*.css"
npm run lint:html -- "surname.name/lab1/**/*.html"
```
