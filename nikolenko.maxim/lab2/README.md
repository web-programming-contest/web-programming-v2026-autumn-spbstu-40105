# Лабораторная работа 2

## Задание

Реализовать функцию `analyzieString`, которая принимает строку и возвращает
объект со следующими полями:

- `letters` — количество букв;
- `digits` — количество цифр;
- `spaces` — количество пробелов;
- `other` — количество остальных символов.

## Реализация

Решение находится в файле `solution.js` и оформлено как ES module. Функция
`analyzieString` экспортируется именованным экспортом.

Основные решения:

- строка обходится циклом `for...of`, поэтому символы вне базовой плоскости
  Unicode (например, эмодзи) считаются как один символ;
- буквы определяются регулярным выражением `\p{L}` с флагом `u`, то есть
  учитываются латиница, кириллица и другие алфавиты;
- цифры определяются выражением `\d`, пробельные символы (пробел, табуляция,
  перенос строки) — выражением `\s`;
- все символы, не попавшие в предыдущие категории, увеличивают счётчик `other`;
- функция возвращает новый объект и ничего не выводит в консоль.

Пример результата для строки `Hello, мир! 123`:

```text
{ letters: 8, digits: 3, spaces: 2, other: 2 }
```

## Запуск

Из корня репозитория курса (требуется Node.js версии из `.nvmrc`):

```bash
node --input-type=module -e "import {analyzieString} from './surname.name/lab2/solution.js'; console.log(analyzieString('Hello, мир! 123'))"
```

Вместо `surname.name` подставьте название своего каталога.
