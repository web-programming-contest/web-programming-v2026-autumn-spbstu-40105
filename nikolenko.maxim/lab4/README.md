# Лабораторная работа 4

## Задание

Создать класс `Library` с полями `name` и `books` (книга: `title`, `author`,
`year`, `genre`), методами `addBook(book)`, `removeBook(title)` и геттером
`booksCount`. Для коллекции библиотек реализовать функции: группировка книг по
жанру (`Map`), уникальные авторы, группировка по году издания, уникальные годы,
книги заданного автора.

Интерфейс: карточки книг с кнопкой «Удалить», форма добавления книги, добавление
и удаление библиотек. Добавление и удаление выполняются асинхронно через
`Promise` и `setTimeout()`, список обновляется автоматически, состояние хранится
в `localStorage`.

## Реализация

- `model.js` — класс `Library` и функции коллекции: `groupBooksByGenre`,
  `getUniqueAuthors`, `groupBooksByYear`, `getUniqueYears`, `getBooksByAuthor`.
  Входной массив не изменяется.
- `main.js` — интерфейс. Функция `delay` оборачивает действие в `Promise` с
  `setTimeout`, `runAction` выполняет его, сохраняет состояние в `localStorage`
  и перерисовывает список. Состояние также сохраняется при закрытии вкладки
  (`beforeunload`) и восстанавливается при загрузке.
- `index.html`, `styles.css` — разметка и оформление. Для проверки заданы
  атрибуты `data-testid`: `entity-list`, `entity-form`, `entity-card`,
  `delete-entity`.

## Запуск

Модули ES требуют HTTP-сервера. Из каталога лабораторной выполните `npx serve .`
(или `python3 -m http.server`) и откройте `http://localhost:3000` (или
`http://localhost:8000`) в браузере.
