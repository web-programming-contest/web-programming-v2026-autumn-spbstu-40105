# Лабораторная работа 3

## Задание

Вариант 8. Реализуйте функцию shuffleArray(arr), которая перемешивает элементы
массива в случайном порядке.

## Реализация

Берет рандомный индекс, вставляет в новый спискок, удаляя из старого, пока
старый список не опустеет

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
