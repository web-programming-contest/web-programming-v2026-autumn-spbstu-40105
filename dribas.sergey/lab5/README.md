# Лабораторная работа 5

## Задание

Вариант 8.

Создайте приложение для бронирования билетов на фильмы. Приложение должно
включать:

- Список фильмов с основной информацией (постер, название);
- Форму бронирования с валидацией данных;
- Подтверждение бронирования. Функциональность:
- просмотр списка фильмов;
- выбор фильма → переход к форме бронирования;
- заполнение формы с валидацией;
- Отправка формы (имитация) → показ подтверждения. Примечание: Обязательные
  поля: Имя, Email, Телефон. Дополнительные поля: Дата сеанса, Время, Количество
  билетов, Тип билета.

## Реализация

Приложение написано на React (JavaScript) со сборщиком Vite. Экраны «форма» и
«подтверждение» переключаются состоянием `isConfirmed` из хука `useState`;
выбранный фильм хранится в состоянии `selectedMovie`. Данные формы читаются из
`FormData` при отправке, валидация — регулярными выражениями, без сторонних
библиотек.

Корневой узел разметки — `<main data-testid="app">` согласно публичному
контракту CI. Обязательные селекторы задачи: `movie-card`, `booking-form`,
`booking-name`, `booking-email`, `booking-phone`, `booking-submit`,
`booking-confirmation`. Чтобы приложение работало без интернета, постерами
фильмов служат стилизованные цветные плашки с жанром фильма.

## Запуск

Перейти в каталог лабораторной работы и установить зависимости: npm install

Запустить сервер для разработки: npm run dev

Продакшен-сборка: npm run build
