# Лабораторная работа 4

## Задание

Вариант 8 — товары и категории.

1. Создать класс `Product` с полями id, name, categories, price; методами
   добавления/удаления категорий и геттером количества категорий.
2. Написать функции группировки, поиска уникальных категорий, фильтрации по цене
   и категориям.
3. Реализовать UI: карточки товаров, форма создания, кнопки удаления. Все
   операции добавления/удаления выполнять асинхронно через Promise +
   setTimeout(). Сохранять состояние в local storage.

## Реализация

Проект разделён на два ES-модуля:

- `model.js` — логика данных: именованные экспорты класса `Product` (методы
  `addCategory`/`removeCategory`, геттер `categoryCount`) и пяти функций для
  работы с коллекцией товаров.
- `main.js` — пользовательский интерфейс: чтение формы через `FormData`,
  отрисовка карточек через `createElement`, делегирование события клика на
  кнопки удаления.

Добавление и удаление товара инкапсулированы в функции, возвращающие `Promise`,
внутри которого применяется `setTimeout` с задержкой 500 мс — это имитирует
сетевую задержку, при этом DOM и `localStorage` обновляются только после
выполнения асинхронной операции. Список товаров восстанавливается из
`localStorage` при загрузке страницы.

Обязательные селекторы контракта CI: `[data-testid="entity-list"]`,
`form[data-testid="entity-form"]`, `[data-testid="entity-card"]`,
`[data-testid="delete-entity"]`.
