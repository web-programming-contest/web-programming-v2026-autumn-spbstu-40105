# Лабораторная работа 1

## Задание

Вариант 8

Сверстать флаг Японии, сам красный круг в центре сделать с помощью position:
absolute, разместив его точно по центру (чтобы он оставался по центру даже если
увеличить размеры флага)

## Реализация

Страница содержит блок <main> с заголовком и контейнером флага. Флаг реализован
в виде вложенных div-элементов

Родительскому элементу .flag задано position: relative, что делает его точкой
отсчёта для вложенного абсолютно позиционированного элемента. Кругу .circle
задано position: absolute в сочетании с top: 50%, left: 50% и transform:
translate(-50%, -50%). Эта связка гарантирует, что центр круга всегда совпадает
с центром флага независимо от его размеров

## Запуск

Откройте `index.html` в браузере.
