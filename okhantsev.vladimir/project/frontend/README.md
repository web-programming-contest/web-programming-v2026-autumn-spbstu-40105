# Лабораторная работа 5

## Задание

React-приложение интернет-магазина гаджетов «Gadget Hub». Пользователь может
просматривать главную страницу, каталог и карточки товаров, фильтровать товары
по цене, типу и цвету, сортировать их и листать постранично. Зарегистрированный
пользователь добавляет товары в корзину, выбирает часть из них, оформляет заказ
и смотрит историю заказов. Данные о товарах, авторизации и заказах приходят с
Go-бэкенда через REST API.

## Реализация

Стек: React 19, TypeScript, Vite, react-router-dom. Фронтенд собирается с
помощью Vite и взаимодействует с бэкендом по OpenAPI-спецификации.

Структура `src/`:

```text
src/
├── main.tsx            # точка входа: StrictMode, BrowserRouter, StoreProvider
├── App.tsx             # маршруты (/login, /catalog, /cart, /)
├── store.tsx           # StoreProvider — глобальное состояние (товары, корзина, авторизация)
├── storeContext.ts     # контекст и хук useStore()
├── api.ts              # типизированный клиент openapi-fetch + ошибка ApiError
├── schema.ts           # типы, сгенерированные из swagger/openapi.yaml
├── types.ts            # алиасы типов и локальный CartItem
├── cartStorage.ts      # сохранение корзины в localStorage
├── catalogUtils.ts     # фильтрация, сортировка, пагинация, границы цен
├── normalize.ts        # перевод значений бэкенда в русские подписи
├── config.ts           # адрес API (VITE_API_URL или localhost:8080)
├── index.css           # все стили
├── components/         # Layout, Header, Footer, Modal, CartControl,
│                       # ProductCard, ProductModal, SimpleCard, Carousel,
│                       # CatalogFilters, PriceRange
└── pages/              # Home, Catalog, Cart, Login
```

Ключевые решения:

- **Состояние** — `StoreProvider` держит товары, корзину и авторизацию и отдаёт
  их всем компонентам через контекст (`useStore()`). При старте загружает товары
  с API и молча обновляет их при возврате на вкладку.
- **Корзина** — хранится в `localStorage` (модуль `cartStorage`) и
  синхронизируется с состоянием; повторная авторизация не теряет содержимое.
- **Авторизация** — сессия живёт в cookie: браузер шлёт её с каждым запросом
  (`credentials: 'include'`). Маршруты `/catalog` и `/cart` защищены компонентом
  `Protected`, при 401 приложение разлогинивает пользователя по событию
  `session-expired`.
- **Типизация API** — `schema.ts` генерируется из спецификации командой
  `npm run types`, а клиент `openapi-fetch` проверяет пути и тела запросов на
  этапе компиляции.
- **Каталог** — фильтры (цена, тип, цвет), сортировка (новизна, популярность,
  цена), пагинация по 12 товаров. Логика вынесена в чистые функции
  `catalogUtils.ts`.
- **Главная** — бесконечная карусель на ручной анимации через
  `requestAnimationFrame`; клик по карточке открывает товар в каталоге (или
  ведёт на вход для неавторизованных).

## Запуск

Бэкенд (Go):

```bash
cd backend
go run ./cmd
```

Фронтенд:

```bash
cd frontend
npm install
npm run dev
```

Главная страница откроется на `http://localhost:3000`. По умолчанию фронтенд
обращается к API на `http://localhost:8080`; адрес можно переопределить
переменной окружения `VITE_API_URL`. Из корня проекта оба сервиса запускаются
одной командой `make frontend` и `make backend`.

Проверка качества: `npm run build` (строгая проверка типов `tsc` + сборка Vite).
