# Лабораторная работа 1

## Задание

Вариант 11. Создать список задач, где каждый элемент списка имеет разную иконку
вместо классических маркеров, в зависимости от статуса задачи:

- Задача выполнена – ✅;
- Задача отменена – ❌;
- Задача в процессе выполнения – ⏳.

Иконки добавляются с помощью псевдоэлементов CSS, используя символы Unicode.

## Реализация

Страница состоит из заголовка и списка задач. Статус каждой задачи задаётся
классом на элементе `<li>`: `completed`, `canceled` и `in-progress`. Иконки
добавляются через CSS-псевдоэлемент `::marker`, выводящий соответствующий символ
Unicode перед текстом.

## Запуск

Откройте `index.html` в браузере.
