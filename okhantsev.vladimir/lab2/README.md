# Лабораторная работа 2

## Задание

Вариант 11. Реализовать функцию `reverseWords`, которая разворачивает символы
каждого слова в строке, сохраняя порядок слов и пробелы между ними.

## Реализация

Экспортируется функция `reverseWords`. Строка разбивается по пробелам, символы
каждого слова разворачиваются и слова собираются обратно через пробел.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
