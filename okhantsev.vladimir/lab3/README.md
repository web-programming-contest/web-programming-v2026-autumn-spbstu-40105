# Лабораторная работа 3

## Задание

Вариант 11. Реализовать функцию `findMaxSubarraySum(arr, n)`, которая находит
максимальную сумму подмассива длины `n`.

## Реализация

Экспортируется функция `findMaxSubarraySum`. Используется скользящее окно: сумма
первого окна вычисляется напрямую, затем окно сдвигается, добавляя новый элемент
и убирая старый, и отслеживается максимальная сумма.
